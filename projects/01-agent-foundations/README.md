# Project 01: Agent Foundations

## Objective
Build a single-agent orchestrator with deterministic control flow.

## Build Requirements
- One input contract and one output contract.
- At least two tool integrations.
- Timeout, retry, and fallback behavior.
- Structured logs for each orchestration step.

## Success Checks
- Runs are reproducible for fixed inputs.
- Failures include actionable diagnostics.
- Tool calls are constrained by explicit policy.
