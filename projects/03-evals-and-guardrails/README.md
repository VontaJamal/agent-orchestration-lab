# Project 03: Evals and Guardrails

## Objective
Create quality and safety gates that prevent risky releases.

## Build Requirements
- Eval dataset covering nominal and adversarial cases.
- Automated pass/fail rubric.
- Guardrails for unsafe actions and policy violations.
- Regression dashboard (even if lightweight).

## Success Checks
- Any quality regression fails CI.
- Guardrails block and log invalid actions.
- Evaluation results are reproducible.
