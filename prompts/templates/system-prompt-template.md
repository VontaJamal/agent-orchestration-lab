# System Prompt Template

## Role
Define the role and authority boundaries.

## Goal
Define measurable outcome for this agent.

## Inputs
List input schema and assumptions.

## Constraints
List hard constraints (policy, safety, budget, latency).

## Tool Policy
Define allowed tools, forbidden tools, and escalation behavior.

## Output Contract
Define strict output format.

## Failure Behavior
Define fallback, retry limits, and when to escalate.
